# AlarmControl 개인정보와 로컬 데이터 안내

[English](PRIVACY.md) | **한국어**

AlarmControl은 구조적으로 오프라인입니다. 최종 앱에는 `android.permission.INTERNET`,
네트워크 클라이언트, 원격 분석, 계정 기능이 없습니다. 자동 매니페스트·클래스패스 검사가
이 경계가 바뀌면 Debug/Release 빌드를 실패시킵니다. WorkManager의
`ACCESS_NETWORK_STATE`는 시스템 제약을 읽을 뿐 데이터를 전송할 수 없습니다.

## 일시적인 처리

Android는 로컬 텍스트 규칙, 번들 분류기, 사용자가 명시적으로 켠 로컬 LLM이 평가할 수
있도록 제목과 본문을 리스너에 전달합니다. 기본값에서는 이 내용이 현재 처리 작업의
메모리에만 존재합니다. 시간 초과, 모델 오류, 신호 누락 시 기존 규칙 경로로 돌아갑니다.

## 기기에 저장하는 데이터

켜진 기능에 따라 앱 전용 Room/DataStore/files 저장소에 다음 항목이 존재할 수 있습니다.

- 사용자가 입력한 규칙 이름, 모드, 우선순위, 동작, 조건 트리와 조건 비교값
- 이름 있는 프로필과 규칙 구성, 설정, 보존 기간, 로컬 동의 항목
- 판정 메타데이터: 패키지, 채널 ID, Android/ML 카테고리, ML 신뢰도, 실제·관찰 규칙 ID와
  동작, 시각, 통계 제외 여부
- 제한된 빈도 상태: 일시적인 리스너 키의 역변환 불가능한 HMAC, 무작위 occurrence ID,
  패키지·채널, 마지막 게시 시각. 원본 리스너 키는 저장하지 않으며 occurrence는 10,000건
  이하로 제한하고 로컬 정리가 가장 긴 24시간 창 밖의 행을 제거합니다.
- 제한된 설명 노드: 활성/관찰 lane, 조건 종류, 결과, 깊이, 순서
- 일별 전체·동작·활성/관찰 규칙·카테고리·패키지/채널·앱·로컬 시간대·의미 분류·
  ML 적용·교정 집계
- 패키지별 카테고리 및 7종 의미 교정·관찰 횟수와 신뢰도
- 안정적인 추천 닫기 키와 소스·작업·대상 종류·결과·변경 수·시각만 담은 제한된 자동화 감사
- 외부 자동화를 켰을 때 앱 전용 Preferences에 보관하는 무작위 설치별 인증 토큰. 이 값은
  로그·감사 기록·백업에 포함하지 않습니다.
- 사용자가 명시적으로 가져와 앱 전용 저장소에 둔 선택형 양자화 LLM 모델
- 사용자가 명시적으로 동의한 경우에만 길이를 제한한 제목·본문의 AES-256-GCM 암호문.
  키는 내보낼 수 없는 Android Keystore 키이며 `SECRET` 알림과 사용자가 제외한 앱은
  저장하지 않고 암호문은 7일 뒤 만료합니다.

설치 앱 이름과 아이콘은 화면 표시 시 해석하며 알림 내용으로 저장하지 않습니다.

## 내보내거나 알림 평문으로 저장하지 않는 데이터

알림 내용은 목록·통계 행, 로그, 피드백, 트레이스, 백업에 절대 넣지 않습니다. 다음 항목도
영속화하지 않습니다.

- 알림에서 복사한 규칙 트레이스 비교값
- LLM 프롬프트, 생성 reasoning, 자유 형식 모델 출력
- 백업 비밀번호와 암호화 키
- 기울기 또는 런타임 학습 말뭉치

선택형 상세 암호문은 사용자가 고른 기록 한 건에서만 읽습니다. 기능 끄기에 성공하면 설정을
꺼진 상태로 바꾸기 전에 모든 암호문과 키를 삭제합니다. 삭제에 실패하면 설정을 켜진 상태로
유지하고 다시 시도하도록 안내합니다. 일반 로그에는 고정 오류 문구만 사용해 알림 내용이
logcat에 들어가지 않게 합니다.

## 로컬 AI와 학습

경량 TFLite 모델·어휘·라벨은 앱에 포함됩니다. 선택형 MediaPipe 모델은 다운로드하지
않으며 사용자가 로컬 파일을 선택하면 앱 전용 저장소에 원자적으로 복사합니다. 모든 추론은
기기에서 수행됩니다. 교정은 SQL 집계와 축소 사전분포만 조정하며 클라우드 또는 런타임
역전파를 수행하지 않습니다.

## 백업 v6

Storage Access Framework 내보내기·가져오기 요청은 로컬 전용입니다. 백업 v6에는 규칙,
프로필, 선택한 설정, 의미 분석 범위, breakdown 완전성 정보, 채널·앱·시간대·의미별 일별
요약과 지원 조건을 담을 수 있습니다.
패키지별 학습 투표는
비밀번호 기반 PBKDF2-HMAC-SHA256 + AES-256-GCM 봉투 안에서만 선택적으로 포함합니다.
평문 백업은 이식성을 위한 형식이므로 파일을 받은 사람이 읽을 수 있다고 간주해야 합니다.
새 암호화 백업 비밀번호는 8자 이상이어야 하며 기존의 짧은 비밀번호 백업도 계속 복원할
수 있습니다. 복원은 미리보기와 검증 후 트랜잭션으로 병합 또는 교체하며 v1~v5도 계속
지원합니다.

설치별 자동화 토큰, 빈도 occurrence 상태와 HMAC 키, 가져온 LLM 모델, 알림 내용,
LLM reasoning은 백업하지 않습니다. Android OS 클라우드 백업도 앱에서 비활성화합니다.

## 사용자 제어와 플랫폼 경계

보존 설정은 활동과 일별 기록을 독립적으로 제한합니다. 원본 활동은 최신 10,000건,
조건 트레이스는 최신 1,000건으로도 제한합니다. 일별/오늘 통계는 알림 게시 당시 저장한
로컬 날짜를 사용하고 구버전 행만 시각으로 호환 집계합니다. 선택형 알림 상세는 최대 7일만
보관하며 앱별 제외를 지원합니다. 설정에서 암호화 상세, 활동, 피드백, 인사이트, 전체
로컬 데이터를 지울 수 있으며 전체 삭제는 추천 닫기 기록, 가져온 모델 파일, 키, 설정도
제거합니다.

AlarmControl은 다른 앱의 알림 채널을 직접 수정할 수 없습니다. 채널 버튼은 사용자가 직접
선택할 수 있도록 Android 시스템 설정을 엽니다. 외부 자동화는 기본적으로 꺼져 있으며
명시적 opt-in과 회전 가능한 설치별 토큰을 모두 요구하고 로컬에서 호출 빈도를 제한합니다.
